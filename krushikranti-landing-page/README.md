# KrushiKranti (कृषीक्रांती) 🌱

**शेतकऱ्यांच्या प्रगतीचा आधुनिक सोबती (Empowering Farmers with Technology)**

KrushiKranti is a web platform designed to bridge the gap between farmers and consumers, eliminating middlemen and ensuring fair pricing (Hamibhav) for agricultural produce.

## 🚀 Features
- **Direct Market Access:** Farmers can sell directly to premium markets.
- **Kisan Credit Card (KCC):** Information and registration assistance.
- **Crop Management:** End-to-end guidance from sowing to harvesting.
- **Language:** Fully localized in Marathi for accessibility.

## 🛠️ Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Responsive Design, Flexbox, Grid)
- FontAwesome (Icons)
- Google Fonts (Noto Sans Devanagari)

## 📂 Project Structure
- `index.html`: Main landing page.
- `legal/`: Contains Privacy Policy, Terms, and Refund policies.
- `css/`: Custom styling.
- `assets/`: Images and logos.
